# Customer Churn Prediction

Predict which telecom customers are likely to cancel their subscription using Machine Learning.

## Problem
Telecom companies lose revenue when customers churn. This model identifies at-risk customers early so the business can take action.

## Dataset
- Source: IBM Telco Customer Churn (Kaggle)
- 7,043 customers | 21 features

## Results
| Model | Accuracy |
|-------|----------|
| Random Forest | 79.56% |

## Key Findings
- TotalCharges, MonthlyCharges, and tenure are the strongest churn predictors
- Month-to-month contracts have the highest churn rate
